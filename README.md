## 诚实边界

- **Z 维五类内容待喂入**（投喂 6 项待喂入之一——槽位数声明非内容
  声明，不虚称已建）；

- **打捞账演示态**（种子 1 条=本仓建制递归先例；真实打捞由执行端按
  投喂包流程入账——append_dredge() 验收权威=执行端回执 AR-4）；
- **Y 权重向量未标定**（schema 定义≠权重标定——标定须真实打捞样本，
  INC-002 候选登记）；
- **零评分纪律**：dredge 命中=确定性双向子串（M07 机制锚），非相似
  度模型非评分——涌现判定仍归 quartet_toolkit；
- **命名裁决留痕**：netaeon 中文名"打捞之网"（归航路由）不动，启藏
  以 qicangaeon 独立命名（纪元族第六员）——同中文名冲突由英文主键
  消解，两网分工在案；
- 投喂两处判定 adjusted（ring-25→ring24 / 19 仓库 designed→done）——
